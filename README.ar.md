## نبذة عن الأداة

**اشرب شاي ☕ (TeaBreak)** هو جسر إشعارات فورية متقدم ومبني خصيصًا لبيئة **Google Antigravity**.

أثناء عمل المساعد الذكي على مهام برمجية طويلة (مثل تشغيل الاختبارات الشاملة، أو بناء الحزم، أو كتابة ميزات معقدة)، يضطر المطور إلى أحد أمرين:
1. الجلوس ومراقبة الشاشة بانتظار انتهاء المساعد من جولته.
2. الابتعاد عن الجهاز والانشغال بأمر آخر، ليعود بعد دقائق ويكتشف أن المساعد توقف مبكرًا بانتظار رد المستخدم أو بسبب خطأ تنفيذي.

**يقدم اشرب شاي الحل الأمثل:**  
يقوم النظام برصد لحظة انتهاء جولة المساعد (Stop Event) عبر الخطافات الأصلية (Native Hooks)، وتصنيف ما حدث بدقة رياضية وفنية عبر 4 حالات تشغيلية معتمدة، وإرسال إشعار فوري خفيف إلى هاتفك المحمول عبر تطبيق ntfy لتكون دائمًا على علم بحالة المساعد دون الحاجة لمراقبة الشاشة.

## المميزات الهندسية الأساسية

- **نقل فوري بدون خوادم محلية (Push-Only Architecture):** لا وجود لأي Daemons، ولا خدمات خلفية، ولا استطلاع دوري (Polling Loops)، ولا استهلاك لموارد المعالج أو الذاكرة.
- **اعتماد كامل على مكتبة بايثون القياسية (Pure Python Standard Library):** لا يتطلب تثبيت أي حزم خارجية عبر `pip`. يعمل مباشرة بـ 100% كود بايثون 3 القياسي (`urllib.request`, `json`, `ctypes`, `subprocess`, `os`, `sys`, `secrets`).
- **بدون روبوتات معقدة أو حسابات (Zero Credentials):** لا حاجة لإنشاء بوت تليجرام، ولا ويب هوك ديسكورد، ولا توثيق Firebase، ولا كلمات مرور.
- **حماية تامة من اختراق أنظمة التشغيل (Zero OS Control Policy):** يلتزم الكود بالحدود الآمنة للهندسة البرمجية ولا ينفذ أي أوامر للتحكم بنظام التشغيل.
- **قارئ أنابيب آمن لويندوز (Windows Named Pipe Resilient Reader):** معالجة متقدمة لأنابيب ويندوز والـ EOF المتأخر والمدخلات الفارغة أو المشوهة دون تعليق أو انهيار.
- **منع الإشعارات المكررة (Deduplication Engine):** تنظيف تلقائي لأي تسجيلات سابقة مكررة لضمان وصول إشعار واحد دقيق لكل حدث توقف.

## طرق التثبيت

### الطريقة الأولى: المعالج الذكي (Master Wizard) — *الموصى بها*

أسهل طريقة للمستخدمين:
1. افتح مشروعك في Antigravity.
2. انسخ محتوى الملف [`MASTER_WIZARD.md`](MASTER_WIZARD.md) وأرسله للمساعد.
3. سيقوم المعالج التفاعلي بإرشادك خطوة بخطوة:
   - اختيار لغة الإشعار (العربية أو الإنجليزية).
   - اختيار تحميل الكود مباشرة من GitHub أو استخدام النسخة المدمجة المطابقة رقميًا.
   - اختيار النطاق (مشروع محلي أم بلجن عام).
   - توليد قناة آمنة وعشوائية 128-bit.
   - التحقق من تفعيل الحماية في `.gitignore`.
   - اختبار وصول الإشعار لهاتفك بموافقتك الصريحة.

---

### الطريقة الثانية: التثبيت اليدوي عبر موجه الأوامر (CLI)

#### المتطلبات المسبقة:
- تثبيت Python 3.8 أو أحدث على جهازك.
- تحميل تطبيق **ntfy** مجانًا على هاتفك ([Android](https://play.google.com/store/apps/details?id=io.heckel.ntfy) / [iOS](https://apps.apple.com/app/ntfy/id1625396347)) أو فتح `https://ntfy.sh`.

#### التثبيت في المشروع الحالي فقط (Workspace Hook):
```bash
python notify_on_stop.py --install --lang ar
```
أو مع تحديد القناة ومقتطف المهمة:
```bash
python notify_on_stop.py --install --topic your_secret_topic --lang ar --include-task
```

#### التثبيت كبلجن عام لجميع المشاريع (Global Plugin):
```bash
python notify_on_stop.py --install-global --lang ar
```

## الأمان وحماية الخصوصية

1. **حماية الـ Git الإلزامية (Fail-Closed Git Protection):**  
   يقوم النظام بفحص ملف `.gitignore` للتأكد من تجاهل ملف الإعدادات الحساس الذي يحوي اسم القناة. إذا تعذر التحقق أو كانت هناك قواعد تلغي التجاهل (`!negation`)، يتم إيقاف الحفظ فورًا لحماية سرية القناة.
2. **عدم تسريب الأكواد أو المدخلات (Privacy by Default):**  
   في الوضع الافتراضي، لا يتم إرسال أي محتوى من البرومبت أو رد المساعد أو مسارات الملفات الحساسة؛ يُرسل فقط اسم المشروع وحالة التنفيذ.
3. **صفر عمليات تجسس أو قياس عن بعد (Zero Telemetry):**  
   لا توجد أي خوادم وسيطة تجمع بيانات الاستخدام أو تراقب الأداء. الاتصال يتم مباشرة وبشكل مشفر بين جهازك وخادم ntfy عبر HTTPS.

## فحص الحالة والاختبار

### فحص الحالة الفنية والإعدادات:
```bash
python notify_on_stop.py --status
```
يُظهر هذا الأمر حالة تسجيل الخطافات، واللغة، والقناة المشفرة جزئيًا، والميزانية الزمنية للشبكة دون إرسال أي طلب خارجي.

### إرسال إشعار فحص اتصال حقيقي (اختباري):
```bash
python notify_on_stop.py --test
```
يُرسل إشعارًا تجريبيًا واحدًا لتأكيد وصول التنبيهات لهاتفك.
